# RushLab

**Agent-driven traffic scenario lab for the San Ysidro border approach, Tijuana.**

Ask *"what's the cheapest way to cut the morning wait at San Ysidro?"* — RushLab
loads the corridor from OpenStreetMap, simulates rush-hour traffic in SUMO, tests
interventions, and returns a ranked before/after comparison with stated assumptions.

> Status: D1 — scaffolding and data reconnaissance complete. Domain modules land next.

## What it does

- **Network layer** — OSM street network → graph; bottleneck detection, centrality,
  min-cut capacity analysis (networkx)
- **Demand layer** — demand estimated from land use and calibrated against BTS
  border-crossing volumes; lane-type splits (General / Ready / SENTRI)
- **Simulation** — SUMO microsimulation via TraCI; border modeled as a
  capacity-controlled sink calibrated to CBP wait-time data
- **Signal optimization** — Webster baseline plus genetic algorithm; offsets,
  green splits, cycle length for the approach corridor
- **Agent layer** — MCP server exposing domain tools; project skills for repeatable
  workflows; Graphify knowledge graph for focused agent context

## Works with your assistant

The repo is agent-agnostic: neutral definitions live in `agent/` and every
tool-specific file is generated by `scripts/sync_agent_config.py` (CI fails on drift).

| Assistant | Instructions | Skills | MCP | Graph reminder |
|---|---|---|---|---|
| opencode | `AGENTS.md` via `opencode.json` | `.opencode/skills/` | `opencode.json` | `.opencode/plugins/graphify.js` |
| Claude Code | `CLAUDE.md` → `@AGENTS.md` | `.claude/skills/` | `.mcp.json` | `.claude/settings.json` |
| Codex | `AGENTS.md` | `.agents/skills/` | `.codex/config.toml` | `.codex/hooks.json` |

To add a skill, MCP server, or hook, edit the corresponding file under `agent/`
and run:

```bash
uv run python scripts/sync_agent_config.py
uv run python scripts/agent_doctor.py
```

Two one-time prompts cannot be pre-accepted from the repo: Codex asks to trust
the project and approve its hooks (`/hooks`); Claude Code asks to trust the
workspace and its MCP server on first use.

| Feature | Count |
|---|---|
| Highway ways | 7,509 |
| Traffic signal nodes | 200 |

Generated by `scripts/recon_overpass.py`; summary committed under
`data/raw/recon_san-ysidro.json`. OSM counts drift as the map is edited — treat
the committed file as the dated snapshot, not a constant.

## Scope and honesty rules

RushLab produces **relative scenario rankings under documented assumptions**, not
real-world predictions. Northbound only; US side modeled as a boundary sink. See
[`docs/decisions/0001-scope.md`](docs/decisions/0001-scope.md).
